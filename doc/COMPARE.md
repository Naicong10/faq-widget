# 关键词版和 AI 版对比

切换方式：在 `.env.local` 里设置 `ANSWER_MODE=keyword` 或 `ANSWER_MODE=rag`，然后重启 `npm run dev`。不写这个变量时默认是关键词版，避免一打开就调用付费接口。

下面 10 题在 2026-09-27 各跑了一遍。关键词版看汉字重合，AI 版先按向量找最像的 3 条 FAQ，最高分低于 0.55 就直接转人工，否则交给 DeepSeek。

| 问题 | 关键词版 | AI 版 |
|---|---|---|
| 宿舍几点熄灯？ | 答对。`faq-06`，23:30 熄灯 | 答对。同样是 23:30，来源 `faq-06`、`faq-10`、`faq-09` |
| 晚上宿舍什么时候关灯 | 答错。匹配到门禁 `faq-10`（23:00 回宿舍），不是熄灯 | 答对。23:30 熄灯，来源含 `faq-06` |
| 寝室晚上是不是统一断电 | 转人工。字面差太远，对不上 | 转人工。已经检索到 `faq-06`（插座不断电），但模型仍回复 `[NO_ANSWER]`，没有据此作答 |
| 校园卡丢了怎么补办？ | 答对。`faq-12`，App 挂失，工本费 20 元 | 答对。同一条答案 |
| 学生卡找不到了怎么挂失 | 转人工。「学生卡」和「校园卡」重合不够 | 答对。挂失补办，来源含 `faq-12` |
| 饭堂每天几点开门 | 答对。`faq-20`，食堂营业时间 | 答对。同一条答案 |
| 家里没钱可以先报到吗 | 转人工。只想起「报到」，给了相关问题建议 | 答对。绿色通道，来源含 `faq-05` |
| 熄灯后可以点蜡烛吗 | 转人工。FAQ 里没有蜡烛 | 转人工。检索到熄灯资料后，模型回复 `[NO_ANSWER]`，没有编造 |
| 怎么办理护照 | 转人工 | 转人工。最高分不够 0.55，没有调用模型 |
| 今天北京天气怎么样 | 转人工 | 转人工。没有调用模型 |

结论：原题两种都能答对。换一种说法时，关键词版会漏掉（学生卡、绿色通道），还可能答到相邻问题（关灯答成门禁）。AI 版能接住这些换说法，资料里没有的问题也不会编造。第 3 题说明模型有时过严：资料里已经写了「只关顶灯、插座不断电」，它仍然拒绝回答。
